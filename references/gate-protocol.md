# 关卡判定协议

关卡判定必须写入 `GATE.md`。

## 状态取值

- `PASS`：没有剩余阻塞问题。
- `CONDITIONAL_PASS`：只剩局部问题，每个问题都有缓解方案，且下一阶段可以吸收风险。
- `BLOCK`：至少缺少一个必需产物，或存在一个硬性阻塞条件。

## 关卡文件模板

```markdown
# 关卡：阶段 N - 名称

**状态**: PASS | CONDITIONAL_PASS | BLOCK
**检查时间**: YYYY-MM-DD
**检查人**: 用户 / Agent

## 已通过项
- [x] ...

## 条件通过项
- [ ] ...
缓解方案：...

## 阻塞项
- [ ] ...
修复动作：...

## 判定理由
...

## 下一步动作
...
```

## 隐式触发

如果用户要求进入下一阶段，必须先检查当前阶段关卡。如果缺少 `GATE.md`，先运行 `scripts/gate_check.py`，再要求解决阻塞项或明确批准条件通过。
