# 回退协议

当后续工作推翻早期假设时，必须使用回退。

## 常见路径

| 情况 | 回退 |
|---|---|
| 结果不支持假设 | 阶段 3 -> 阶段 2 |
| 大纲缺少足够证据 | 阶段 4 -> 阶段 3 |
| 草稿故事线不连贯 | 阶段 5 -> 阶段 4 |
| 审查发现无证据支撑的主张 | 阶段 6 -> 阶段 4 或阶段 3 |
| 审查发现实验设计缺陷 | 阶段 6 -> 阶段 2 |

## 回退记录

回退记录写入 `stage/rollback/`。

```markdown
# 回退：阶段 X -> 阶段 Y

**时间**: YYYY-MM-DD
**原因**: ...
**问题**: ...
**受影响产物**:
- ...
**恢复计划**:
- ...
**预计成本**: ...
```

## 限制

- 不要静默删除后续阶段产物。
- 如果已经存在内容冻结记录，修改冻结内容前必须写解除冻结说明。
- 如果同一问题导致三次回退，停止并要求人工决策。
